Redirection Handling Analysis:

TOKENIZATION (tokenize_input -> parse_input_loop):

1. handle_redirection: USED to identify <, >, <<, >> and create the corresponding tokens (T_REDIR_*, T_APPEND, T_HEREDOC).

Parsing (parse_tokens):

handle_redirection_parser: USED when a redirection token is encountered. It creates a t_redir struct, assigns the type, reads the next token as the filename/delimiter, duplicates it, and adds the struct to the current t_cmd using add_redir_to_cmd.

add_redir_to_cmd: USED by the parser.

is_redirection: USED by the parser to check token types.

Heredoc Pre-processing (process_input):

handle_all_heredocs: USED. Called before execution. It iterates through all commands and redirections.

handle_heredoc: USED by handle_all_heredocs. Reads input until the delimiter, writes to a pipe, and stores the read end file descriptor (heredoc_fd) in the t_redir struct.

create_heredoc_pipe: USED by handle_heredoc.

Execution-time Redirection Setup (handle_parent_builtin or handle_child_process):

setup_redirections: USED. This is the main function called to apply all redirections for a command just before it runs.

process_single_redirection: USED by setup_redirections. Handles one redirection entry at a time.

validate_redirection: USED by process_single_redirection. Checks for missing filenames etc.

handle_redirection_type: USED by process_single_redirection. Dispatches to the correct handler based on redir->type.

handle_input_redir: USED by handle_redirection_type. Opens the file and dup2s to STDIN_FILENO.

handle_output_redir: USED by handle_redirection_type. Opens/creates/truncates the file and dup2s to STDOUT_FILENO.

handle_append_redir: USED by handle_redirection_type. Opens/creates/appends to the file and dup2s to STDOUT_FILENO.

handle_heredoc2: USED by handle_redirection_type. Takes the pre-filled redir->heredoc_fd (from handle_all_heredocs), dup2s it to STDIN_FILENO, and closes the original FD.

print_redirection_error: USED by process_single_redirection on failure.

Cleanup:

restore_std_fds: USED in handle_parent_builtin and cleanup_execution to restore original stdin/stdout after redirection.

close_heredoc_fds: USED in process_input after execution to close any remaining heredoc read FDs stored in the t_redir structs.

Conclusion on Redirections:

You handle heredocs before execution starts, storing the necessary file descriptor.
